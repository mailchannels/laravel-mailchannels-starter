# laravel-mailchannels-starter

Laravel starter app: sign-up verification, password reset and a contact form sending through the MailChannels Email API, with signed webhooks and a no-account stub mode.

## Support

This project is supported by the MailChannels team on a best-effort basis. The best way to get support is to file an issue on GitHub: https://github.com/mailchannels/laravel-mailchannels-starter/issues

If you are a MailChannels customer and have a problem with the operation of the MailChannels service, you can get support at https://support.mailchannels.com/
